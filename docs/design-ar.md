# الواجهة الجديدة والتجربة داخل الكاميرا

تُبرز الصفحة صور HEAD 12029 وHEAD 12028 التي اختارها المالك، ببطاقات أكبر وخط Manrope محلي وألوان كحلية وزرقاء. تُعرض خطوات التجربة وسياسة بقاء صور الكاميرا على الجهاز وروابط الإدارة الفعلية. تدعم الواجهة الهاتف والكمبيوتر ولوحة المفاتيح وتقليل الحركة؛ لا توجد خطوط أو مكتبات جديدة محملة من طرف خارجي.

حُذف موديل Éclipse 01 التجريبي من العرض واختيار الموديلات ومن كود المجسم التجريبي. عند التشغيل، يحذف الخادم فقط السجل الأولي الذي يحمل `id: demo` و`demo: true`، ثم لا يعيد إنشاءه. تبقى المنتجات الحقيقية وتعديلاتها وملفاتها كما هي. يُنشأ الكتالوج فارغًا في التثبيت الجديد حتى تُستورد المنتجات الحقيقية.

يفتح «Essayer sur mon visage» الكاميرا مباشرة على الكمبيوتر والهاتف. يظل إذن المتصفح مطلوبًا. تظهر صور الموديلات في شريط فوق الكاميرا، وتبدّل النظارة في التدفق نفسه دون إغلاقه أو إعادة طلب الإذن. يظهر زر إعادة المحاولة عند الفشل فقط. تتاح قائمة نصية بديلة وتوضيحات المعاينة في «À propos de l’essayage»، وزر التصوير يحفظ الصورة الأصلية بالنظارة دون عناصر الواجهة.

يحتفظ العرض بإطار الكاميرا كاملًا وبالخلفية المموّهة التي اختارها المالك. يتزامن الفيديو والنظارة والحجب كما في المحرك السابق؛ لم تتغير هندسة المجسمات أو قياساتها أو صور المنتجات. تستخدم الشاشة الممتدة مساحة المتصفح المتاحة دون الاعتماد على وضع الفيديو الأصلي المنفصل.

## التحقق

```bash
npm test
npm run test:browser
CAMERA_FIXTURE=/path/to/face.y4m TRYON_PRODUCT_ID=head-12028-models-v2 MODEL_SWITCH=1 node scripts/camera-smoke.mjs
CAMERA_FIXTURE=/path/to/face.y4m TRYON_PRODUCT_ID=head-12028-models-v2 node scripts/mobile-camera-smoke.mjs
CAMERA_FIXTURE=/path/to/face.y4m node scripts/loading-smoke.mjs
```

تغطي الاختبارات الكاميرا التلقائية، وتبديل الصور المصغرة مع استمرار التدفق، والتصوير، والإغلاق وإعادة الفتح، ورفض الإذن وإعادة المحاولة، والتحميل البطيء وإلغاء الطلبات، وتدوير شاشة الهاتف المحاكى ومحاذاة العرض، والإدارة وحذف النموذج التجريبي. تُراجع الواجهة بصريًا على أحجام شاشة مختلفة. هذه فحوص Chromium محلية؛ النشر على EC2 والتجربة على هاتف المالك يبقيان بعد تحديث الخادم.

## تطبيق التحديث

```bash
cd ~/tryit
git pull --ff-only origin main
sudo systemctl start tryit-backup.service
```

بعد نجاح النسخة الاحتياطية:

```bash
sudo systemctl restart tryit
```

أعد تحميل الصفحة. لا يلزم رفع GLB أو صور المنتجات مجددًا أو تشغيل سكربت استيراد؛ إزالة السجل التجريبي تحصل عند بدء الخادم. الخط مرخّص تحت OFL؛ ملف الرخصة مضمّن مع الخط.
