# HEAD 12028 — Col.400 : prototype photo-référencé

Fichier autonome : `public/products/head-12028/head-12028-col400.glb`.
Photo catalogue : `public/products/head-12028/front.jpg`, conversion JPEG de la photo fournie IMG_2529. Les métadonnées EXIF (dont la localisation) ont été retirées sans changer les pixels décodés. Les autres photos du propriétaire ont servi de références visuelles, sans être publiées dans le dépôt.

## Fidélité et limites

Modélisation manuelle à partir des cinq photos fournies (IMG_2529, 2530, 2533, 2536 et 2552) : contour frontal, ouvertures des deux verres, pont, monture bleu marine, branches ouvertes, charnières et marquage latéral simplifié. Ce fichier n'est ni un scan ni un modèle constructeur. Les dimensions, la section des branches, les faces cachées, les courbures et les matériaux sont estimés. La teinte bleutée des reflets est approximée ; aucun effet de polarisation optique n'est simulé.

La largeur frontale nominale de 140 mm et le profil des branches sont des hypothèses de modélisation, pas des mesures du produit. Ne pas les présenter comme caractéristiques commerciales. Les inscriptions `Mod.12028 Col.400` sont visibles sur les photos du propriétaire. L'essayage porte une mention d'approximation ; il ne garantit pas le bon ajustement. L'occlusion des branches derrière un visage et l'aspect des matériaux dépendent encore du rendu de l'application.

## Structure et ancrage

GLB 2.0 sans textures externes, 9 maillages, axes X largeur, Y haut, +Z vers la caméra. L'extension de métadonnées `asset.extras.lunetteCaba` indique l'ancrage au niveau des verres (`[0, -0.004, 0]`) et la largeur frontale de référence. Le chargeur utilise cet ancrage pour éviter que la longueur des branches ne décale la monture sur le visage. Les fichiers tiers sans ces métadonnées conservent leur centrage précédent.

Pour régénérer l'actif, sur une machine avec Blender 4.3 :

```bash
blender --background --threads 2 --python scripts/build-head-12028.py
```

Blender n'est pas nécessaire sur EC2 pour utiliser le GLB déjà généré. Le message Blender concernant l'absence de Draco est informatif ici : la compression Draco n'est pas activée et le fichier standard ne dépend pas de ce décodeur.

## Ajout sur le serveur existant

L'import est hors ligne pour éviter une écriture concurrente du catalogue. Prévoir quelques secondes d'arrêt. Depuis le compte Ubuntu :

```bash
cd ~/tryit
git pull --ff-only origin main
sudo systemctl stop tryit
node scripts/import-head-12028.mjs
sudo systemctl start tryit
```

Redémarrer le service même si l'import signale une erreur, puis examiner l'erreur avant toute nouvelle tentative. L'import copie les deux fichiers dans `uploads/` avec des noms basés sur leur contenu, puis ajoute uniquement `head-12028-col400`. Il ne remplace aucun produit existant et ne modifie pas la démo. Une seconde exécution préserve les modifications de l'administrateur. Pour corriger ultérieurement ce modèle déjà importé, utiliser les outils d'édition de l'administration ou une migration dédiée ; relancer l'import ne remplace pas l'ancien GLB.

Les fichiers référencés dans `uploads/` sont inclus dans la sauvegarde S3 existante. Le fichier source versionné dans `public/products/` et le script de génération restent disponibles dans GitHub.
