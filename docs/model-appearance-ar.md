# تحسين مظهر نموذج HEAD في الموقع

المرجع هو ملف GLB الذي أرسله المالك، مع مراجعة صورة المنتج الأصلية أيضًا. أظهر عرض الملف في محرر ثلاثي الأبعاد إطارًا داكنًا وعدسات رمادية مائلة للأزرق، بينما بدا عرض الكاميرا أفتح بكثير وكانت العينان واضحتين خلف العدسات. كان المحرك يستبدل خريطة اللون الأصلية بخامات موحدة ويضيء المشهد بإضاءة قوية؛ لذلك اختلف المظهر حتى مع استخدام هندسة الملف نفسه.

## ما تغير

- تُحفظ خريطة اللون الأصلية للإطار والعدسات، بما فيها التفاصيل والكتابات الموجودة في الملف. تبقى الخامات منفصلة لضبط لمعانها وشفافيتها بشكل مستقل.
- يستعمل الإطار لمعانًا أهدأ، وتصبح عتامة العدسات 0.96 بدل 0.68 لتقترب من المرجع. هذه قيمة مظهر وليست قياسًا لنفاذية العدسة الحقيقية.
- تُنسخ رؤوس العدسات لعزل اتجاهاتها السطحية عن الإطار، ثم تُعطى اتجاهات ناعمة ومتسقة بدل اتجاهات السطح المولدة التي أظهرت بقعًا ومثلثات لامعة. لا تتحرك المواضع السطحية ولا يزيد عدد المثلثات. عدد الرؤوس يزيد لفصل بيانات الإضاءة فقط.
- تمتد عملية تصنيف الخامة قليلًا عند حافة العدسة على المثلثات الفاتحة فقط لتقليل الحافة المتكسرة، مع الاحتفاظ بالجسر المعتم.
- تقل الإضاءة العامة والمباشرة، ويُرسم المجسم بدقة عرض أعلى عند الحاجة، بحد أقصى 1.5 لكل محور. تبقى صورة إدخال MediaPipe بحجم فيديو الكاميرا، حتى لا تزيد تكلفة التتبّع لمجرد تكبير نافذة العرض.

الملف الثنائي الأصلي والكتالوج لا يتغيران. تعديل الذراعين ومسار حجب الرأس والأذنين يبقيان في مسارهما الحالي. ملفات المنتجات غير المعروفة لا تتلقى إعادة الخامات الخاصة بملف HEAD، لكن ضبط إضاءة المشهد ودقة العرض يسري على المعاينة.

## ما تم التحقق منه

```bash
npm test
npm run test:browser
node scripts/materials-smoke.mjs
node scripts/ears-smoke.mjs
node scripts/temple-visibility-smoke.mjs
CAMERA_FIXTURE=/chemin/visage.y4m TRYON_PRODUCT_ID=head-12028-col400 TRACKING_DROPOUTS=1 node scripts/camera-smoke.mjs
CAMERA_FIXTURE=/chemin/marqueur.y4m TRYON_PRODUCT_ID=head-12028-col400 FRAME_SYNC=1 node scripts/camera-smoke.mjs
```

يتحقق اختبار الخامات من حفظ خريطة اللون وعدم تحريرها أثناء إعداد الخامات، ومن بقاء اتجاهات الإطار الأصلية ومواضعه، واتساق اتجاهات العدسات، والعتامة والجسر وتوزيع الخامات. اختبار الكاميرا يقارن الصورة المركبة بمرجع كاميرا يُرسم عبر مسار WebGL نفسه دون أجسام ثلاثية الأبعاد؛ هذا يمنع اعتبار اختلاف تنعيم إعادة التحجيم بين Canvas وWebGL جزءًا من النظارة. هذه آلية اختبار فقط ولا تضاف إلى التطبيق الفعلي.

## حدود المطابقة

هذه الخطوة تقرّب عرض الموقع من ملف GLB المرجعي. يظل الملف نفسه مولدًا من الصور، ولا يتحول إلى نموذج مصنعي دقيق بتغيير الخامات. خريطة اللون الأصلية تتضمن انعكاسات مصورة؛ حفظها يحافظ على مظهر المرجع، لكنه لا يعني إعادة بناء ضوء غرفة العميل أو محاكاة العدسات والاستقطاب. المطابقة الدقيقة لشكل المنتج وتفاصيله تحتاج تعديل هندسة منظمًا أو CAD موثوقًا ومقاسات واضحة.

## تحديث الموقع

على الخادم `16.192.70.157`:

```bash
cd ~/tryit
git pull --ff-only origin main
sudo systemctl restart tryit
```

ثم تحديث كامل للمتصفح. لا يلزم رفع GLB أو تشغيل سكربت استيراد جديد.
