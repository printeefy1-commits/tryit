# إضافة موديل models-v2

يحتوي الإصدار [models-v2](https://github.com/printeefy1-commits/tryit/releases/tag/models-v2) وقت تجهيز هذه الإضافة على ملف GLB واحد: `head.glb`. يُضاف كمنتج مستقل، ولا يستبدل موديل model-v1 الموجود، الذي صحّح المالك رقمه إلى HEAD 12029.

أكد المالك أن رقم الموديل HEAD 12028؛ يظهر الإطار الكحلي والعدسات الزرقاء في الصور، ولم يُؤكّد رمز اللون المطبوع. يمكن تعديل الاسم في الإدارة. المعرّف الثابت `head-12028-models-v2` يمنع تكرار الإضافة عند إعادة الاستيراد.

## التحضير

- الأصل: 52,458,576 بايت، 1,748,506 مثلث، إطار وعدسات منفصلان بخامات وألوان رؤوس دون صور خامات خارجية.
- بصمة SHA-256 الأصلية مطابقة لبصمة GitHub: `046f50c9b51e6d12d0956db2d60a4b0566c6d0455e5f2a374d8af939b198e0bf`.
- نسخة الويب: `public/products/models-v2/head-blue.glb`، بحجم 2,051,856 بايت، 74,998 مثلث، وخامات الإطار والعدسات وألوان الرؤوس مدمجة، دون احتياج Draco أو ملفات خارجية.
- أصل GLB يبقى في الإصدار دون تعديل. فحص Khronos لنسخة الويب: صفر أخطاء وصفر تحذيرات.
- المحاور محفوظة: X للعرض، Y للأعلى، +Z للأمام. مرجع العرض الأمامي `0.8858` ونقطة تثبيت العدسات `[0, 0.135, 0.19]` بوحدات الموديل. هذه معايرة بصرية وليست قياسًا ماديًا؛ العرض الاسمي للمحرك 14 سم حتى يحدد المالك عرض الإطار الخارجي في الإدارة.
- صورة المنتج المعروضة هي الصورة الثانية التي حدّدها المالك: `2025_09_15_18_26_IMG_2529.HEIC`، محوّلة إلى `product.webp` بدقة 1300×1000 مع تقليل الهوامش الفارغة دون قطع النظارة. تبقى `preview.webp` معاينة منفصلة للمجسّم ولا تُستخدم الآن صورةً للمنتج. الصورة الأولى IMG_2561 مخصّصة لـ HEAD 12029.

ملف `tryon-model-profiles.js` يختار الإعدادات بالبصمة المحددة فقط. الملف المحدّث يحتوي أصلًا خامتَي `Blue_Lenses` و`frame` منفصلتين؛ يحافظ المحرك على الخامتين والألوان وألوان الرؤوس والشفافية والخشونة واتجاهات السطح وعرض الوجهين كما أُعدّت في الملف. لا يستعمل له تصنيف العدسات بالسطوع أو استبدال خامة النظارة. شفافية العدسات 0.5 وخشونتها 0.14 وخشونة الإطار 0.9، كما حدّدها المالك. ضُبطت الأذرع بإعدادات تخص هذا المصدر: رفع تدريجي حتى 1.05 سم، فتح جانبي حتى 0.9 سم، وإطالة خلفية حتى 0.5 سم بوحدات الرأس الاسمية. تعديلات موديل model-v1 (HEAD 12029) السابقة لم تتغير. تظل أقنعة الأذن تقديرية لأن متتبّع الوجه لا يوفر نقاطًا للأذن.

المصدر المحدّث لا يحمل صور الانعكاسات القديمة داخل خامات PBR؛ الإضاءة تأتي من إعدادات المشهد والخامات. لا تحاكي انعكاسات العدسة المكان الحقيقي عبر الكاميرا بدقة. لا يثبت GLB أو التتبّع المقاس أو الملاءمة الفعلية للمنتج.

## تحديث GLB الموجود على EC2

رفع المالك ملفًا جديدًا مكان المصدر السابق في الإصدار نفسه. يقوم `scripts/update-models-v2.mjs` باستبدال GLB للمنتج `head-12028-models-v2` دون إنشاء منتج آخر. يحفظ المسار السابق في `previousModel` وبصمة المصدر السابقة في `previousModelSourceSha256` ولا يحذف الملف السابق. يحدّث الصورة المصغرة المولّدة السابقة فقط، ويُبقي صورة المدير المخصصة إن وجدت. الاسم والعلامة والإظهار والقياسات والحجم والإزاحة تبقى كما هي. إعادة التشغيل بعد تطبيق الملف الجديد لا تعيد كتابة الكتالوج.

يشغّل التسلسل التالي الاستيراد أولًا ليتعامل أيضًا مع جهاز لم يستورد المنتج بعد، ثم يطبّق التحديث على المنتج الموجود.

## الاستيراد والتحديث على EC2

نفّذ سحب التحديث ثم انتظر نجاح النسخة الاحتياطية:

```bash
cd ~/tryit
git pull --ff-only origin main
sudo systemctl start tryit-backup.service
```

بعد نجاح النسخة الاحتياطية، أوقف التطبيق أثناء الاستيراد لتجنب تعديل الكتالوج بالتزامن مع الإدارة:

```bash
sudo systemctl stop tryit
node scripts/import-models-v2.mjs
node scripts/update-models-v2.mjs
sudo systemctl start tryit
```

أعد تشغيل `tryit` حتى إذا فشل الاستيراد، ثم راجع الخطأ. لا تُشغّل سكربت الاستيراد بالتوازي مع التطبيق. يضيف السكربت المنتجات الناقصة فقط. يصحّح اسم موديل model-v1 من «12028» إلى «12029» إذا ظل الاسم الأصلي، ويحافظ على أي اسم مخصص وضعه المدير. تبقى المعرّفات القديمة ومسارات الملفات وإعدادات الحجم والإزاحة والصور والظهور كما هي. ينسخ GLB والصورة إلى `uploads` بأسماء تعتمد على محتواها؛ تشملها النسخ الاحتياطية القائمة. لا تُحذف ملفات أو منتجات سابقة. إعادة الاستيراد لا تعيد إظهار منتج أخفاه المدير ولا تستبدل اسمه أو صورته أو ضبطه.

أعد تحميل الموقع بعد التحديث. لا يلزم رفع ملف 50 ميغابايت من لوحة الإدارة أو تعديل AWS/Nginx.

## إعادة تجهيز الملف والاختبارات

يتطلب تجهيز GLB Blender 4.3 على جهاز العمل فقط:

```bash
blender --background --threads 2 --python scripts/prepare-models-v2.py -- \
  --input /path/to/head.glb \
  --output public/products/models-v2/head-blue.glb
node scripts/preview-models-v2.mjs
```

كانت النسخة السابقة من models-v2 مصدرًا واحدًا بخامات صور؛ بصمتها `a013cbe08e711629e2a47a62560ca87b625dca8a0f20bdd4c6eae92f67c51514`. يبقى ملف الإعدادات المتوافق معها في المحرك للكتالوجات التي لم تطبق التحديث بعد. النسخة الحالية تخفض العدد الإجمالي لمثلثات الجزأين إلى ميزانية مشتركة، وتحافظ على الخامات المعدلة وألوان الرؤوس.

سكربت التجهيز يرفض بصمة مصدر مختلفة؛ لا تُنسخ هذه المعايرة إلى نظارة جديدة تلقائيًا.

```bash
npm test
npm run test:browser
node scripts/authored-model-smoke.mjs
TRYON_MODEL_URL=/products/models-v2/head-blue.glb node scripts/ears-smoke.mjs
TRYON_MODEL_URL=/products/models-v2/head-blue.glb node scripts/temple-visibility-smoke.mjs
TRYON_MODEL_URL=/products/models-v2/head-blue.glb node scripts/occlusion-smoke.mjs
CAMERA_FIXTURE=/path/to/face.y4m TRYON_PRODUCT_ID=head-12028-models-v2 node scripts/camera-smoke.mjs
CAMERA_FIXTURE=/path/to/face.y4m TRYON_PRODUCT_ID=head-12028-models-v2 node scripts/mobile-camera-smoke.mjs
```

الاختبارات تفحص الملف الفعلي والخامات والأذرع وحجب الأنف والرأس في 21 وضعية، واستقلال الإعدادات عن الموديل السابق، وحفظ تعديلات الإدارة وتكرار الاستيراد بأمان، وتشغيل التتبّع والتصوير وإغلاق الكاميرا وتدوير الهاتف المحاكى. تبقى مراجعة المستخدم على جهازه ضرورية لتقييم الملاءمة البصرية، ولم يُنفّذ النشر على EC2 من بيئة العمل هذه.
